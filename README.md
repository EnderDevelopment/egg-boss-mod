# EggBoss

EggBoss is a Minecraft mod that adds a custom boss and a custom egg to the game. This mod is designed for Minecraft Forge and is compatible with Minecraft versions 1.18.2. The mod introduces a new boss entity with unique attributes and a spawn egg that allows players to summon it in the game world.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure that the mod is loaded correctly.

## Use

1. Craft a custom boss egg using the provided recipe or obtain it from loot chests.
2. Right-click on the custom boss egg to spawn the custom boss in the game world.
3. Engage in combat with the custom boss to test its unique attributes and abilities.
